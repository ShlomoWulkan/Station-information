📱 5 מסכי האפליקציה

1

📍 חיפוש לפי מיקום

  • מבקש הרשאת GPS
  • מציג תחנות עד 100 מטר
  • ממויין לפי מרחק
  • אם אין: הודעה נעימה
לחיצה → GPS → Spinner → רשימת תחנות
2

🕐 חיפושים אחרונים

  • שמור ב-AsyncStorage אוטומטית
  • עד 10 חיפושים אחרונים
  • מחיקה בסוויפ שמאלה
  • ריענון בלחיצה
כל חיפוש → נשמר → מוצג ברשימה
3

⭐ מועדפות

  • כוכב על כל תחנה → נשמרת
  • גישה מהירה לתחנות קבועות
  • סידור לפי שם / סדר הוספה
  • מחיקה בסוויפ
⭐ → AsyncStorage → רשימת מועדפות
4

🔢 חיפוש לפי מספר תחנה

  • מקלדת מספרית
  • חיפוש מיידי תוך הקלדה
  • היסטוריה של מספרים שהוקלדו
מספר → API → כרטיס תחנה + אוטובוסים
5

🗺 חיפוש על מפה

  • מפה אינטראקטיבית עם Markers
  • לחיצה על תחנה → Bottom Sheet
  • רשימת אוטובוסים בתחתית
  • מרכוז על מיקום המשתמש
Map → Marker → Bottom Sheet → אוטובוסים

🚀 שלבי פיתוח

1

הקמת פרויקט Expo

יצירת פרויקט בסיסי עם TypeScript, Expo Router, הגדרת RTL לעברית.

pnpm create expo-app . --template blank-typescript
2

עיצוב בסיסי + Theme

הגדרת צבעים, גופנים, מרווחים ב-theme.ts. בניית StationCard ו-BusArrivalRow.

3

Mock Data + UI מלא

כל המסכים עובדים עם נתוני דמו. כך אפשר לפתח UI ללא תלות בשרת.

USE_MOCK=true
4

Cache – מועדפות + אחרונים

בניית useCache.ts, Zustand stores, AsyncStorage ל-favorites ו-recent.

5

GPS + מפה

expo-location לחיפוש לפי מיקום, react-native-maps למסך המפה.

6

שרת Python (FastAPI)

פרוקסי בין האפליקציה ל-API של משרד התחבורה, מחזיר JSON, IP קבוע.

uvicorn main:app --host 0.0.0.0 --port 8000
7

חיבור ל-API אמיתי

החלפת mockData.ts בקריאות אמיתיות לשרת Python, בדיקות End-to-End.
